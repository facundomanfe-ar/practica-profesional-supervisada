En este repositorio se presentan los trabajos hechos por **Juan Facundo Manfé**, estudiante avanzado de Ingeniería Electromecánica en la Universidad Nacional de General Sarmiento (UNGS).
Estos trabajos fueron realizado bajo el marco de la Practica profesional supervizada donde se desarrollo en primer lugar un portal web bajo el marco del proyecto: 

## Proyecto CyT UNGS 2025-2026 "Diseño y fabricación de sistemas embebidos para el reporte instantáneo de costo de energía eléctrica, detección de umbrales de tensión y gestión eficiente de la energía" (Res N° 31474/2025)"
En este proyecto se diseño y puso en funcionamiento un portal web enfocado en la visualización de datos de consumo eléctrico residencial. El sistema permite procesar la información recolectada por hardware de medición y presentarla de manera clara para facilitar la gestión eficiente de la energía.

Tambien se realizo la automatizacion y protocolo de comunicacion entre ESP32 y Jetson, bajo el marco del proyecto:

## "Cinta transportadora remotizada para su aplicación en visión artificial", proyecto IdeI UNGS - CONFEDI - Fundación YPF. 
En este proyecto se coordino con un equipo multidisciplinario de estudiantes para llevar a cabo la automatización integral de la cinta. El trabajo en este repositorio abarca la programación del control y el diseño del protocolo de comunicación bidireccional entre microcontroladores ESP32 y placas NVIDIA Jetson, vinculando el control físico con los algoritmos de visión artificial.
